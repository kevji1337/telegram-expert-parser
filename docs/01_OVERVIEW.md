# TG Parser — Обзор проекта

## Цель

Парсер Telegram-каналов для поиска **экспертных каналов с потенциалом монетизации**: курсы, наставничество, мини-группы, консалтинг. Парсит публичные каналы через Telegram API (Telethon), анализирует метрики и тексты, классифицирует каналы и формирует приоритезированный список для ручного анализа.

## Целевые ниши

1. **AI / Нейросети** (ChatGPT, Midjourney, prompt engineering, автоматизация)
2. **IT / Программирование** (курсы, менторство, карьера в IT)
3. **Бизнес-консалтинг** (предпринимательство, инфобизнес, личный бренд)

Ниши конфигурируются через `keywords.yaml`.

## Высокоуровневый pipeline

```
keywords.yaml (ниши + ключи)
    ↓
[1] Поиск каналов через Telegram SearchRequest по каждому ключу
    ↓
[2] Для каждого канала: GetFullChannel + iter_messages (последние 20 постов) + pinned
    ↓
[3] Метрики (просмотры, реакции, комменты, частота постов)
    ↓
[4] Классификация (expert/news/brand/community/aggregator + маркеры)
    ↓
[5] Анализ качества (1-е лицо, CTA, структура постов, автопостинг)
    ↓
[6] Скоринг: expert_score, monetization_score, analysis_queue_score
    ↓
[7] Рекурсивный поиск по упоминаниям из найденных экспертных каналов
    ↓
[8] Сортировка + отбор шортлиста (топ-20) и декомпозиции (топ-5)
    ↓
[9] Сохранение в CSV (results/) → просмотр через веб-панель
```

## Точки входа

- `python run.py` — парсер в CLI
- `python run_web.py` — веб-панель (Flask, http://localhost:5000)
  - просмотр результатов
  - запуск/остановка парсера прямо из браузера
  - live-логи через polling `/api/parser/logs`

## Ключевые принципы дизайна

1. **Надёжность важнее скорости** — SQLite-кэш, чекпоинты каждые 25 каналов, автосвап аккаунтов при долгом FloodWait
2. **Адаптивный rate-limiting** — задержка между запросами скользит вверх при ошибках и вниз при стабильности (0.1–5.0 сек)
3. **Множественные сигналы** — для классификации канала используются маркеры в about, pinned, постах, ссылках, упоминаниях
4. **Antifraud / false-positive guard** — отдельный детект ботов, агрегаторов, магазинов, новостных каналов
5. **Модульность** — каждый модуль в `src/` имеет одну ответственность (см. ARCHITECTURE.md)
